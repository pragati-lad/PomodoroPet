 # PomoPet 🐱⏰

  A Pomodoro timer with a virtual pet companion that grows as you study!

  ## Features
  - 10 unique cat personalities
  - Cat growth system (ages like real cats)
  - Customizable Pomodoro timer (default: 45min focus / 15min break)
  - Optional camera-based focus tracking
  - Mood & hunger system

  ## Tech Stack
  - Frontend: React + TailwindCSS
  - Backend: Firebase/Supabase
  - Camera Detection: TensorFlow.js
  - Hosting: Vercel/Netlify

  ## Setup
  ```bash
  npm install
  npm run dev
